# Tailwind CSS and Setup Guide

This repository uses Tailwind CSS v4 to generate standard styles for the web application.

---

## Overview

Tailwind CSS lets you write utility classes directly in your HTML elements rather than maintaining long custom CSS stylesheets.

* **Traditional CSS:** Requires maintaining external styles where changes in one place can break layout elsewhere.
* **Tailwind CSS:** Applies utility classes directly to HTML elements for predictable and localized styling.

---

## Automation Scripts

Batch scripts are provided to streamline local setup and compilation:

1. **`setup_and_watch.bat`**: Installs Tailwind packages and starts the live build process.
2. **`install_tailwind.bat`**: Installs the required npm dependencies (`tailwindcss` and `@tailwindcss/cli`).
3. **`watch_tailwind.bat`**: Runs the compilation process in watch mode:  
   `npx @tailwindcss/cli -i ./src/main.css -o ./style.css --watch`

---

## File Structure & Workflow

Pay attention to how CSS files are handled in this project:

1. **`src/main.css`**: The source CSS file where custom rules and theme settings should be added.
2. **`style.css`**: The output CSS file generated by the Tailwind CLI. **Do not edit this file directly**, as it will be overwritten whenever the compiler runs.

## Quickstart

1. Run `setup_and_watch.bat` or `watch_tailwind.bat`.
2. Edit HTML files or `src/main.css`.
3. The build process will automatically update `style.css`.
